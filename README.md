# TORIIA STUDIO 🤍

> **🌐 Подивитися сайт наживо:** [https://den-dombrovskyi.github.io/toriia-studio/]

Сучасний, стильний та адаптивний сайт-візитка для студії краси **TORIIA STUDIO**, розташованої у Запоріжжі (площа Вернадського, пр. Соборний, 152).

## 📋 Опис проєкту
Проєкт розроблено з нуля з акцентом на естетику б'юті-сфери, чистоту коду та бездоганний користувацький досвід. Сайт містить повну інформацію про послуги студії, структурований прайс-лист за категоріями майстрів («Топ-Майстер», «Майстер», «Брови») та зручні інтерактивні елементи інтерфейсу.

## ✨ Основний функціонал
* **Інтерактивний прайс-лист:** Зручне групування послуг за напрямками (Manicure, Pedicure, Нарощування, Complex & Design, Brows & Lamination).
* **Адаптивний дизайн:** Коректне та красиве відображення на будь-яких пристроях — від смартфонів до широкоформатних моніторів.
* **Фірмовий візуальний стиль:** Ретельно підібрані та зкадровані зображення з акуратним розміщенням і сучасна типографіка.
* **Швидкий зв'язок:** Інтегровані посилання для миттєвого переходу в месенджери (Viber, Telegram) та контакти студії.

## 🛠️ Технології
* **HTML5 / Semantic Markup**
* **CSS3 / Flexbox / Grid** (сучасна архітектура стилів)
* **JavaScript** (інтерактивні компоненти)
* **Git & GitHub** (контроль версій та деплой)
